从直觉到定理，用动画看清「割线与切线平行」——再动手解题。

先建立直觉

想象你开车从 A 到 B：平均速度是「总路程 ÷ 总时间」。途中某一瞬间，速度表的读数一定等于这个平均速度——否则你到不了终点。

📏
割线（平均变化率）

连接曲线两端点的直线，斜率 = 整体平均变化。

✏️
切线（瞬时变化率）

贴着曲线某一点的直线，斜率 = 该点导数 f′(c)。

核心画面：在光滑曲线上，总能找到一点 c，使得该点切线与两端割线平行（斜率相等）。

拉格朗日中值定理

若函数 f 在闭区间 [a, b] 上连续，在开区间 (a, b) 内可导，则存在至少一点 c ∈ (a, b)，使得：

f′(c) = f(b) − f(a) b − a
左边：切线斜率 · 右边：割线斜率

条件要记牢

  • 在 [a, b] 上连续（端点也要好）
  • 在 (a, b) 内可导（中间不能有尖角、断点）

几何含义

端点弦的斜率，一定能在曲线内部某处被切线「复制」出来——动画里你会亲眼看到这一点。

小提示：c 的存在性保证了，但不一定唯一；练习里我们求的是满足等式的具体 c。

例题精讲

跟着逐步展开，体会「设方程 → 求导数 → 解出 c」的标准流程。

例 1　f(x)=x²，区间 [0, 2]

步骤 1 · 割线斜率
f(2)−f(0) 2−0 = (4−0)/2 = 2
步骤 2 · 导数
f′(x) = 2x，故要 2c = 2 ⇒ c = 1（∈ (0,2) ✓）
步骤 3 · 验证
切线斜率 f′(1)=2，与割线斜率相同。几何上：切线在 x=1 处与弦平行。

例 2　f(x)=√x，区间 [1, 4]

步骤 1 · 割线斜率
(√4 − √1)/(4−1) = (2−1)/3 = 1/3
步骤 2 · 导数与方程
f′(x)=1/(2√x)，令 1/(2√c) = 1/3 ⇒ 2√c = 3 ⇒ √c = 3/2 ⇒ c = 9/4
步骤 3 · 检验区间
9/4 = 2.25 ∈ (1, 4) ✓。这就是定理保证存在的那个点。

动手练习

求出满足中值定理的 c。可用分数、小数或 π/2 等形式作答。

① f(x)=x²，[0, 2]。求 c。
提示：令 f′(c) = (f(2)−f(0))/2
② f(x)=√x，[1, 4]。求 c。
提示：答案可写 9/4 或 2.25
③ f(x)=sin x，[0, π]。求 c。
提示：f′(x)=cos x，割线斜率为 0
